# Лабораторная работа № 1 — последовательное умножение квадратных матриц

**Твой вариант.** Язык C++17, без OpenMP и без библиотечного умножения.

## Цель
Изучить последовательное умножение двух квадратных матриц, измерить время для разных размеров и проверить правильность вычислений независимой библиотекой NumPy.

## Алгоритм
Матрицы считываются из `A.txt` и `B.txt`. Первая строка каждого файла — размер `N`, далее `N` строк по `N` чисел. Результат записывается в `result.txt` в том же формате.

Результирующий элемент вычисляется по формуле `C[i][j] = sum(A[i][k] * B[k][j])` для `k` от `0` до `N-1`. Реализация — три вложенных цикла, **без распараллеливания**. Порядок циклов: **ijk**. Хранение: `vector<vector<double>>`. Время измеряется только вокруг вызова умножения. Оценка арифметических операций — приблизительно `2*N³`; память для элементов трёх матриц — `3*N²*8` байт (без накладных расходов контейнеров).

## Запуск на Windows (Developer PowerShell Visual Studio)
```powershell
cl /EHsc /O2 /std:c++17 main.cpp /Fe:matrix.exe
py -m pip install numpy matplotlib
py generate.py 200
.\matrix.exe
py check.py
py experiment.py --exe .\matrix.exe --sizes 200 400 800 1200 1600 2000
```

## Запуск на Linux
```bash
g++ -O2 -std=c++17 main.cpp -o matrix
python3 -m pip install numpy matplotlib
python3 experiment.py --exe ./matrix --sizes 200 400 800 1200 1600 2000
```

Для быстрого теста можно указать `--sizes 20 50 100`; для устойчивых замеров — `--repeats 3`. На размерах 1600 и 2000 вычисление и проверка могут занять заметное время.

## Методика эксперимента
Для каждого N скрипт генерирует две матрицы со значениями от -5 до 5 и фиксированным зерном генератора. Затем запускает программу, извлекает время, проверяет результат через `NumPy` и сохраняет данные в `results/results.csv`. График строится по тем же данным и помещается в `results/time_vs_size.png`. При повторном запуске таблица и график обновляются.

## Выводы
Последовательное умножение реализовано вручную тремя циклами. Его вычислительная сложность составляет O(N³), поэтому увеличение размера матриц существенно увеличивает время работы. Правильность каждого результата подтверждается сравнением с NumPy. Итоговые численные выводы следует делать по измерениям на компьютере, на котором проводилась работа.
